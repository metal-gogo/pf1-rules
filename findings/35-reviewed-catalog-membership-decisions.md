# Reviewed secondary-catalog membership decisions

Decision date: 2026-08-21 (America/Mexico_City)

## Outcome

[C] All 25 d20PFSRD-only candidate memberships from finding 31 are resolved.
The spells themselves were already canonical; this decision changes class access
only.

- Fourteen genuinely additional class memberships were added across 13 spells.
- Eleven same-class competing-level claims were resolved without adding duplicate
  class levels.
- AoN, d20PFSRD, and Foundry PF1 claims remain distinguishable from reviewed
  canonical choices.
- No printed field value, Range override, spell identity, or rules text changed.

## Reviewed authority workflow

1. Use AoN when it clearly transcribes the applicable publication.
2. Use Foundry PF1 and d20PFSRD as candidate and catalog evidence.
3. When Foundry PF1 and d20PFSRD disagree, recommend Foundry PF1 and request a
   reviewed decision.
4. When those sources are insufficient, record an explicit reviewed canonical
   override or inspect the printed Paizo publication and official errata.

[C] A class union is not a level union. Adding every class named by an accepted
source does not authorize adding two unqualified levels for the same class. A
same-class level conflict remains one canonical level with every raw source claim
preserved.

## Retained AoN levels

[C] AoN clearly identifies an applicable first-party publication for these
spells. The canonical database keeps the AoN levels and rejects the secondary
catalog alternatives:

- Alpha Instinct: Mesmerist 2, not 3.
- Horrific Doubles: Mesmerist 3 and Psychic 3, not level 4.
- Positive Pulse, Greater: Paladin 4 and Summoner 4, not level 3.
- Soothing Word: Ranger 2, not 3.
- Wither Limb: Spiritualist 6, not 5.
- Vinetrap: Cleric 8, Druid 8, and Oracle 8, not level 5.
- Improve Trap: Inquisitor 3, not 2.

## Deliberate union exceptions

[C] Foundry PF1 omits Bard 5 from Covetous Aura, Bloodrager 1 from Expeditious
Excavation, and Sorcerer 3 from See Beyond. The project owner explicitly approved
adding all classes named by any reviewed source, so these d20PFSRD-only classes
are canonical reviewed union entries. This does not assert that Foundry or the
printed publication contains them.

## Reproducibility requirements

- Preserve the AoN and d20PFSRD observations unchanged.
- Mark added entries with `REVIEWED_CATALOG_MEMBERSHIP_UNION`.
- Attach `manually_resolved` provenance to each added level.
- Mark retained AoN level choices with `REVIEWED_AON_LEVEL_SELECTION`.
- Refuse to append a reviewed membership when AoN already contains the same
  unqualified class; require an explicit level-selection decision instead.
- Replay the decisions with `pnpm ingest:retry-reviewed-overrides`.
