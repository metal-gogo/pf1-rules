# PF1 Rules

PF1 Rules is a local, provenance-first Pathfinder First Edition rules database.
It captures source material as auditable observations, turns reviewed facts into
canonical records, and makes those records available through a command-line
interface and a lightweight web browser.

The project is an evolving research prototype built with TypeScript, Prisma,
and SQLite. Its data and source decisions remain versioned and reproducible
instead of depending on a live rules website.

Start with the **[project index](docs/index.md)** for setup, usage, architecture,
data, schemas, and research notes.
